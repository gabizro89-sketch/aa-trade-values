# AA Trade Scout: shared values

This repo holds `aa-values.json`, the item values for the Roblox game Anime Adventures, worked out from
trade chat by AA Trade Scout and published once a day.

It contains only values, confidence, demand (1-10) and how many trades each item was seen in.
No messages and no player names.

Format: `items` maps an item name to `[value, confidence, demand, trades]`.
Confidence is one of `high`, `ok`, `low`, `none` (not enough data), `list`.
